How this site works

  • Each brand page shows menu categories with typical US price ranges, not one exact national price — most chains do not publish one national price list.
  • The Meal Builder estimates total cost and calories from the items you pick. It is an estimate, not a checkout.
  • Prices were compiled from 2026 secondary menu listings in October 2026. Re-check your local menu or app before ordering, and update the data file when prices change.

Menu Hub v1 — static site, no database, no login. Deploy the files in this repo to any shared hosting public_html folder, or to GitHub Pages.
